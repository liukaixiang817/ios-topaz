# Four own Wi-Fi supplies, default OFF

`--wifi-power-four-vrm-roundtrip` is a separate composition of the current
known-client, current namespace, full source/cache, normal object/AT,
masked CPU and two complete masked CmdDb word captures. It requires explicit
current-word-read dependencies and rejects the independent ARC vote scopes.
It reads sixteen HLOS/DRV2 fields before forming any VRM resource write.
A normal passed observation never supplies masked access permission.

The four names must be selected from this session's complete CmdDb format:
`ldoa5`, `ldoa7`, `ldoa17`, `ldoa25`. Four additional entry ranges join the
three current selected-read passes and full source/namespace closure. Two
fresh masked 128 KiB copies are still compared in full. The four entries
are reselected from each copy and compared with the current normal entries.
The names, table type/version, raw entries, priorities and zero-length
auxiliary data are retained. No cache match or absent entry becomes saved0.

Each single READ uses CMD0 only and retains voltage mV, enable, raw PMIC
mode and headroom mV. A fully returned unsupported value can decline after
complete TCS/source/CPU/private retirement, leaving the writer entirely
unused. Partial delivery, changed source, PAR/CPU/time failure, unmatched
prefix or uncertain restore remains sticky UNKNOWN. No Delete, USB export,
reset or cleanup is admitted from that state.

The own ICNSS minimum requests are 800/1800/1304/3104 mV; maximums are
800/1800/1304/3312 mV. Each voltage is max(saved, requested) within its own
bounds. L5, L7, L17, L25 each receive voltage before enable. Restoration
visits L25, L17, L7, L5 and writes exact saved enable before saved voltage.
The source's four load and explicit delay values are zero. Mode/headroom
are preserved; this code neither forces HPM nor claims hardware settling.

The writer must use the same eligible TCS and complete snapshot restored
by this session's returned READ. Each of sixteen READ and eight WRITE
transactions requires its own new trigger edge, new IRQ, all issued DONE,
idle and ACK. Every command RW register, wait value and saved enable is
restored. No IRQ enable/type or extra high restore trigger is written.

One combined interval is anchored at the first READ's original start:
50 ms, 256 steps and 1024 engine events. The writer's local bound never
renews it. The original 200 ms owner/source/CPU bound, all 68 work samples,
slowest estimate, READ50+25 ms reserve and full retirement remain. Parent
normal-object admission covers the entire new VRM record. Complete engine
and access prefixes are rechecked before CPU restoration and after normal
namespace/source closure before returning to known Delete.

The full new parent is `CURRENT_PRIVATE_FOUR_VRM_RAW_V1`, 2072064 bytes;
its prepared-current record is 236032 bytes. Existing ARC READ/WRITE records
remain unused and UNOBSERVED. V9 projects the existing resident error,
phase, TCS/IRQ, word-byte counts and mask state into the same sixteen rows;
it performs no post-failure hardware or clock reads. UNKNOWN still follows
the original append, local all-DAIF/G1 mask, optional GOP and nonreturn hold.
The firmware log capacity is 10.25 MiB; the manifest-bound host reader
accepts that exact added size and its full 14.25 MiB plus 128-byte
firmware/native snapshot. The complete raw-capacity static assertion retains
its original reserve. This fits the original packager's 24-bit FFS size,
without changing FFS format or removing any original firmware file.

This is a temporary supply roundtrip before MSS. It provides no MSS/MSA,
SMEM/DMA/MPU/VMID/EL3, remote NV, WLFW/ath10k or network permission. A new
exact host profile, affected checks, two serial whole EFI-XNU models,
original codec, source audit, independent freeze, one offline helper,
current integrity/FASTBOOT and publication are still required before any
physical attempt. Old consumed sessions cannot run this scope.
